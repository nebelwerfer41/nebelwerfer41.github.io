# nebelwerfer41

Public repositories: film production, PDFs, weather, and input testing.

[Public Repository Index](https://nebelwerfer41.github.io/) · [GitHub profile](https://github.com/nebelwerfer41)

| Repository | Purpose |
| --- | --- |
| [41weather](https://github.com/nebelwerfer41/41weather) | Hourly and daily MeteoAM forecasts with location search, marine data, sunrise, sunset, and lunar phases. |
| [Bluetooth HID Tester](https://github.com/nebelwerfer41/bluetooth-controller-ios-test) | Log keyboard, mouse, pointer, and gamepad events exposed by the browser. A test page for iOS devices. |
| [Flash Suite Export](https://github.com/nebelwerfer41/flash-callsheet-msr-template) | MSR report template for Movie Magic Scheduling, with illustrated export instructions for Flash Suite. |
| [Flash Back](https://github.com/nebelwerfer41/flashBack) | Manage crew and department call times, with text import and export. |
| [Flash SCHM](https://github.com/nebelwerfer41/flashSCHM) | Schedule actor preparation for costume, hair, and makeup. Assign staff, view a timeline, and import or export Excel files. |
| [Flash Sides](https://github.com/nebelwerfer41/flashSides) | Select, reorder, and merge separate scene PDFs into a single document. |
| [Flash Watermark](https://github.com/nebelwerfer41/flashwatermark) | Create recipient-specific PDF watermarks in the browser and download the copies as a ZIP file. |
| [Stripboard Studio](https://github.com/nebelwerfer41/stripboard-studio) | View and edit Movie Magic Scheduling stripboards. Import and export MSD and MMSX files locally in the browser. |

Features, setup instructions, and limitations are documented in each repository’s README.
